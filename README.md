I built a smile-activated camera at BlueStamp Engineering using a Raspberry Pi, Python, and OpenCV. The camera detects smiles in a live video feed and can automatically take photos when someone smiles. Users can turn automatic capture on or off and set the delay between photos. I also integrated Google Drive uploads and designed a 3D-printed cover to mount the camera.

This repository documents the project from prototype to final build. It includes milestone write-ups, demo videos, Python code, project photos, and STL files for the custom cover.
